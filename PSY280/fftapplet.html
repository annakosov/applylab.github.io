Spatial Frequency Analysis

Fourier Image Reconstruction Demo

Any image can be broken down into a set of sine waves, and conversely, any image can be created from summing a set of sine waves. This is called Fourier analysis. Keeping only the strongest spatial-frequency components gives us a coarse approximation of the original. Adding more components gives you a sharper representation.
Choose an image from the drop-down menu or upload your own. Then, use the slider to change the number of visible components.
